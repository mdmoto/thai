# 泰国行为校准包（v1）

这个数据包的目标是把“模型假设”逐步替换为可追溯的真实行为证据，同时保留每个结论的数据边界。机器不会把公开网页的点赞、销量文案、评分或评论数当作成交量，也不会把它们直接用于拟合转化率。

机器可自动收集的公开信号：商品与竞品价格、促销、可得性文字、评分/评论元数据、公开规格、保修和消费者常见问题。客户在创建专业版研究时可填写产品网址，另可提供最多 5 个公开来源；系统只访问允许抓取的公开 HTTPS 页面，并保存 URL、时间、内容哈希、字段和限制说明。

## 一、客户需要提供的最小真实选择数据

每一行代表同一决策场景中的一个备选项，不是单独的一笔汇总销售额。

| 字段 | 必填 | 说明 |
|---|---:|---|
| `choice_set_id` | 是 | 同一次选择中的备选项共享同一 ID；上传后会重新匿名化 |
| `alternative` | 是 | 选项名称；上传后会替换为无业务含义的序号 |
| `chosen` | 是 | 该选项是否被选中 |
| 任一模型特征 | 是 | 例如 `price_log_ratio`、`review_proof`、`convenience` 或 `distance_friction`；同一选择组中必须有变化 |
| 时间、渠道、地区 | 推荐 | 用于留出集与跨渠道校验，不进入个人画像 |
| 促销标记、库存、运费 | 推荐 | 用来区分真实价格效应与促销/履约效应 |

不要上传姓名、邮箱、手机号、完整地址、Cookie、设备 ID 或任何可直接识别个人的信息。当前拟合门槛为 `max(20, 特征数 × 5)` 个有效选择组；模型收敛后标记为“已拟合，待回测”，只有通过时间切分或留出样本验证后才可称为已验证。

## 二、客户在系统中得到什么

- 专业版自动执行公开市场扫描；失败、限制或禁止抓取不会中断模拟。
- 公开证据只更新竞品/产品属性和后续研究问题，不能替代真实订单或选择实验。
- 客户提供的选择数据可拟合该客户研究的系数；平台只在至少 5 个独立贡献、500 个选择组后保留去标识的系数摘要，绝不共享原始行。
- 报告会显示每条结论的来源级别、使用方式与限制。

完整机器可读定义见 [`thailand_behavior_calibration_pack_v1.json`](../../data_catalog/calibration/thailand_behavior_calibration_pack_v1.json)。
