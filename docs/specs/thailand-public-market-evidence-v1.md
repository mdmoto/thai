# 泰国公开市场证据规格（v1）

## 目标

对每次专业版研究中的公开网页证据，形成可审计、可重复的输入：客户给出商品、竞品或公开评测网址，系统提取可归因的公开产品事实，并明确其不能说明的内容。

## 输入与边界

- 最多 20 个公开 HTTPS 来源；客户界面默认最多 5 个补充来源。
- URL 在抓取前去除常见追踪参数并去重。Shopee、Lazada 与 TikTok Shop 每个域名最多保留 10 个商品页，以形成有意义的 SKU/价格面板；其他域名最多 3 页，避免单一平台主导定性结论。
- 仅访问 robots.txt 允许的页面，使用限速；拒绝登录墙、验证码、反爬挑战、私有接口和浏览器 Cookie。
- 系统不收集个人资料、账号内容、私信或需要登录才能取得的信息。

## 可接受字段

| 字段 | 可用于 | 不可用于 |
|---|---|---|
| 标价、促销、运费、可得性文字 | 竞品选择集、价格与履约属性 | 实际成交量或价格弹性拟合 |
| 公开评分和评论数量 | 信任/评价证据、后续问卷问题 | 销量、转化率或市场份额 |
| 规格、保修、品牌主张 | 产品属性对比 | 独立质量验证 |
| 公开评论主题 | 消费者访谈与调研问题设计 | 代表性人群比例 |

## 验收标准

1. 每条证据有来源 URL、采集时间、内容哈希、平台、可观察字段和限制说明。
2. 同一主张若来自单一商业页面，在报告中标记为商家/品牌主张。
3. 公开证据只能更新产品/竞品属性，不可替换真实选择模型系数。
4. 抓取失败必须失败开放：保留现有模型先验并在报告说明，不中断研究。
5. 客户真实订单、A/B 或 conjoint 选择数据须按行为校准包另行验证，不能由网页证据替代。

## 发布检查

- 新增来源平台前，检查其 robots 规则、条款与适用隐私要求。
- 每个新增提取字段需加入来源级别和限制说明。
- 更新采集规则时，运行 `tests/test_market_research.py` 与研究流程回归测试。
