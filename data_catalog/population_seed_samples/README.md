# Population seed samples

No licensed Thai household microdata is stored in this directory.

The Phase 2 technical validation creates deterministic synthetic decision-unit
seeds at runtime. Each run writes a content-addressed input manifest containing
the dataset ID, source profile, source timestamps and URLs, variable mapping,
row count, missing-value counts, SHA-256, seed and permission statement.

This placeholder must not be replaced with customer or licensed microdata
unless its authorization, retention, de-identification and access controls are
recorded first.
